# FlowDesk

> Plataforma de **Service Desk interno** para gerenciamento de solicitações e tickets entre setores e departamentos.

## Sobre o projeto

O **FlowDesk** é uma plataforma desenvolvida para centralizar e organizar solicitações internas entre diferentes setores de uma organização.

A proposta é permitir que colaboradores possam registrar demandas, acompanhar seu andamento e encaminhá-las ao setor ou responsável adequado, proporcionando maior controle e transparência sobre o fluxo de atendimento.

O sistema contará com uma **dashboard Kanban**, permitindo visualizar os tickets de forma organizada conforme seu status e acompanhar visualmente a evolução de cada solicitação.

## Objetivos

* Centralizar solicitações internas em uma única plataforma;
* Facilitar a comunicação entre diferentes setores;
* Organizar e acompanhar o fluxo de tickets;
* Melhorar a visibilidade sobre demandas pendentes e concluídas;
* Fornecer uma interface visual baseada em Kanban;
* Armazenar e gerenciar os dados utilizando MongoDB.

## Principais funcionalidades

As funcionalidades planejadas para o projeto incluem:

* [ ] Criação de tickets;
* [ ] Visualização e gerenciamento de tickets;
* [ ] Definição de prioridade;
* [ ] Categorização das solicitações;
* [ ] Encaminhamento entre setores;
* [ ] Atribuição de responsáveis;
* [ ] Controle de status;
* [ ] Dashboard Kanban;
* [ ] Histórico de movimentações;
* [ ] Sistema de usuários e permissões.

## Tecnologias

O projeto será desenvolvido utilizando:

* **MongoDB** para armazenamento dos dados;
* **Backend/API** para gerenciamento das regras de negócio;
* **Frontend Web** para interação com a plataforma;
* **Kanban** para representação visual do fluxo de atendimento.

> As tecnologias e ferramentas utilizadas poderão ser atualizadas conforme a evolução do projeto.

## Estrutura do projeto

A estrutura do projeto será definida e documentada conforme o desenvolvimento das aplicações de frontend, backend e banco de dados.
